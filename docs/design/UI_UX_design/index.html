Mở màn hình chính

Mỗi trang có nút “Bảng demo” ở góc phải dưới để chuyển vai trò (Chuyên viên / Trưởng nhóm / Quản lý), giao diện sáng/tối và các trạng thái (kho trống, mất kết nối, AI bận…). Mở console trình duyệt để xem các sự kiện analytics EV-xx được phát.

Ghi chú

  • Prototype tĩnh, chạy trực tiếp bằng cách mở file trong Chrome/Edge — không cần máy chủ, không tải tài nguyên ngoài (TC-04).
  • Bố cục 3 vùng ở ≥ 1280px; 768–1279px: kho tài liệu thành drawer, vùng xem thành lớp phủ (Blueprint §2.4).
  • Token màu đã kiểm tra tương phản WCAG 2.1 AA; màu biểu đồ đã chạy validator (Blueprint §3.6.3).
  • Figma frames chưa được tạo: cần cấp quyền Figma connector trước.
